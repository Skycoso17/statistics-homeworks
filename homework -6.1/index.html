Riemann and Lebesgue Integration

Same integral, different way of looking at the function.

01

The main idea

Both Riemann and Lebesgue integration try to answer the same question: how much does a function contribute in total?

The difference is not mainly in the final number. The difference is in how we organize the information.

Riemann asks:

“Where are the points?”

We divide the x-axis into small pieces. In each piece, we look at the height of the function.

Lebesgue asks:

“What values do the points have?”

We group together points that give similar function values, even if those points are far apart on the x-axis.

The core difference: Riemann cuts the domain. Lebesgue groups the values.
02

How Riemann thinks

Imagine that we want to estimate the area under a curve. The most natural idea is to divide the horizontal axis into many small intervals.

In every interval, we build a rectangle. If the intervals are small enough, the rectangles should approximate the curve.

∫ f(x) dx ≈ Σ f(xᵢ*) Δx

The formula looks technical, but the logic is simple: small width × approximate height, repeated many times.

Riemann logic
divide x-axis→look at function height→build rectangles→add areas
03

How Lebesgue thinks

Lebesgue changes the question. Instead of asking what happens in a small interval of x, we look at the possible function values.

For example, suppose many different x-values produce a value near 2. Lebesgue groups all of them together and asks: how much of the domain produces values near 2?

∫ f dμ ≈ Σ value × size of its preimage

Again, the formula is less important than the idea: function value × how much space it occupies.

Lebesgue logic
group by function value→measure how much x-space belongs to each group→multiply→add contributions

06

Experiment 1 · sin(x)

What is happening?

The sine function is smooth and regular. Nothing strange happens: the curve changes gradually and has no jumps.

How does Riemann see it?

Small vertical slices work very well because nearby points have similar heights.

How does Lebesgue see it?

Points with similar heights are grouped together. The groups change smoothly because the function itself is smooth.

∫₀^π sin(x) dx = 2

Lesson: for a smooth function, both viewpoints are natural and converge to the same answer.
07

Experiment 2 · x²

What is happening?

The function grows steadily from 0 to 1. It is continuous and monotone.

Riemann view

The rectangles gradually increase in height as x increases.

Lebesgue view

Low values occupy more of the left part of the domain, while higher values appear closer to x=1.

∫₀¹ x² dx = 1/3

Lesson: this is a clean example for studying numerical error, because the function itself introduces no difficulty.
08

Experiment 3 · Step function

f(x)=1 for x<0.5,    f(x)=3 for x≥0.5

What is happening?

The function only takes two values. Half of the interval is at height 1 and the other half is at height 3.

Riemann view

We split the x-axis and determine whether each small interval lies in the lower or upper region.

Lebesgue view

We immediately see two groups: value 1 occupies half the domain, and value 3 occupies the other half.

1·0.5 + 3·0.5 = 2

Lesson: when a function takes only a few values, the Lebesgue viewpoint can be more natural than dividing the domain.
09

Experiment 4 · |x−0.5|

What is happening?

The function is symmetric. The same height can appear on both sides of the center.

Riemann view

The left and right sides are treated as different locations in the domain.

Lebesgue view

Equal heights are grouped together, even if they come from two separate x-regions.

∫₀¹ |x−0.5| dx = 1/4

Lesson: Lebesgue does not care whether points are close together. It cares about the value they produce.
10

Experiment 5 · 1/√x

What is happening?

Near x=0 the function becomes extremely large. But this happens in a very small region.

Riemann view

The first intervals near zero become difficult, because the rectangle heights grow rapidly.

Lebesgue view

Very large function values occupy only a tiny part of the domain, so their total contribution can still be finite.

∫₀¹ 1/√x dx = 2

Lesson: a function can become extremely large without having an infinite integral. What matters is both the height and how much space that height occupies.
11

Experiment 6 · Indicator function

f(x)=1 for x<0.5,    f(x)=0 otherwise

What is happening?

The function is simply marking a set: it is 1 inside the set and 0 outside.

Riemann view

We approximate the area of the region where the function is equal to 1.

Lebesgue view

The integral is directly the size of the set on which the function equals 1.

∫ f = measure of [0,0.5) = 0.5

Lesson: indicator functions show very clearly how integration and measure are connected.
12

Experiment 7 · sin(x)/x

What is happening?

The formula is undefined at x=0, but the function approaches 1 there.

Riemann view

Once we define f(0)=1, the function behaves like an ordinary continuous function.

Lebesgue view

A change at a single point does not matter for the integral, because one point has measure zero.

∫₀^π sin(x)/x dx ≈ 1.851937

Lesson: isolated points usually do not matter for integration, while the global behavior of the function does.
13

Experiment 8 · Dirichlet function

D(x)=1 for rational x, 0 for irrational x

What is happening?

Rational and irrational numbers are mixed everywhere. No matter how much we zoom in, we always find both types of points.

Riemann view

Every tiny interval contains values 0 and 1. So Riemann never finds a stable local height.

Lebesgue view

Lebesgue asks how much space belongs to the value 1. The rationals have measure zero, so almost all the interval contributes value 0.

Lower sums stay at 0
Upper sums stay at 1

Lebesgue integral = 0

Lesson: Riemann sees permanent local chaos. Lebesgue sees that the “problematic” set is negligible in measure.
14

Experiment 9 · Thomae's function

T(x)=1/q if x=p/q in lowest terms, 0 if x is irrational

What is happening?

Rational points create spikes, but most spikes are very small.

Riemann view

The large spikes are rare enough that small intervals can still control the total oscillation.

Lebesgue view

All non-zero values occur on the rational numbers, which form a set of measure zero.

Riemann integral = Lebesgue integral = 0

Lesson: dense discontinuities do not automatically destroy integrability. What matters is how “large” the problematic set really is.

16

Final conclusion

The most important result of this homework is not a formula. It is a change in perspective.

Riemann tries to understand a function by looking at small regions of the domain. Lebesgue tries to understand it by grouping points according to the values they produce.

Riemann asks “where are the points?”
Lebesgue asks “what values do the points have?”

For regular functions, both approaches lead to the same integral. For irregular functions, the Lebesgue viewpoint can still make sense even when Riemann's local rectangle picture breaks down.
